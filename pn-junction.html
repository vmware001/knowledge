01

载流子从哪里来：本征激发与掺杂

半导体的全部用处，来自它的载流子浓度可以被外部条件在十几个数量级的范围内调节。 PN 结做的事情，是把这种可调性固化进一个空间结构：在同一块晶体的两侧， 一边富电子，一边富空穴。要理解这个结构，先要理解两种载流子各自的"户口"。

1.1 本征激发：成对产生的电子与空穴

绝对零度下，价带被填满、导带完全空着，晶体不导电。温度升高后，一部分价带电子获得 足以跨越禁带的热能（≥ Eg），跃迁到导带，同时在价带中留下一个 空缺——空穴。这两个载流子成对出现、数量恒等：n = p。

单位体积、单位时间的产生率对温度极其敏感，本质上是一个玻尔兹曼因子：

G0 ∝ T3 exp​( −EgkT ) 1.1

与此同时，导带里的电子会不断落回价带与空穴复合。复合是双体过程——必须有一个电子 和一个空穴同时在场，因此复合率正比于两者的浓度乘积：

R = β n p 1.2

热平衡时产生与复合严格抵消（细致平衡），G0 = R，于是产物被锁定为一个只与温度有关的常数：

n0p0 = ni2 = NcNv exp​( −EgkT ) 1.3 · 质量作用定律

式 1.3 看似平淡，却是整篇文章的支点。它说的是"乘积固定"，而不是"各自固定"： 你可以把电子浓度抬高十个数量级，空穴浓度就会相应地压低十个数量级，乘积纹丝不动。 PN 结的全部非平衡行为，都是在这一约束下展开的。

1.2 掺杂：把一种载流子变成"多数"

在硅中掺入五价元素（磷、砷），施主原子在禁带中靠近导带处引入浅能级，室温下几乎全部电离， 向晶格贡献一个自由电子；掺入三价元素（硼），受主在靠近价带处引入浅能级，贡献一个空穴。 电离后的杂质离子被固定在晶格上，不能移动——这一点在后面会变得至关重要。

n 型材料的电中性条件是"负电荷总量 = 正电荷总量"：电子数与电离受主数之和，等于电离施主数。 在完全电离、且 ND ≫ ni 的常态下，电子浓度几乎精确等于施主浓度：

nn0 ≈ ND，    pn0 = ni2ND 1.4

关键洞察：少子浓度是"被锁定"的量

掺杂从 1015 增加到 1017，多子浓度只变 100 倍，少子浓度却变化 10 000 倍—— 因为它按 1/N 反比下降。这意味着少子浓度对任何能够扰动 np 乘积的因素 （温度、光照、外加偏压）都呈现指数级敏感。

器件物理中几乎所有"有趣"的现象，都发生在少子身上。多子只是背景，少子才是主角。

02

产生与复合：微观过程的收支平衡

载流子不是永恒存在的。它们有明确的"出生"途径和"死亡"途径，而器件的工作点， 本质上就是这两条通道的流量之比。

2.1 产生：载流子的三种出生方式

  • 本征热激发——晶格振动把能量传递给价带电子，使其跨越禁带。产生率随温度按 exp(−Eg/kT) 上升，是唯一在暗处、无偏压时依然存在的产生机制。
  • 杂质电离——浅能级上的载流子被热激发到导带（或价带）。室温下通常已全部电离，之后不再贡献新的产生。
  • 外部激发——光子的能量注入（光生载流子），或由外部电路通过电极注入（电注入）。正向偏置的 PN 结正是靠这一机制维持非平衡态。

2.2 复合：三条竞争通道

复合必须同时满足能量守恒与动量守恒，因此不同材料、不同工作条件下占主导的机制并不相同。 下图把四种主要路径画在同一张能带图上：

在硅这种间接带隙材料中，导带底与价带顶的晶体动量不同，带间辐射复合需要声子参与， 概率极低（这也是硅无法做高效发光器件的原因）。因此硅中的复合几乎全部经由缺陷能级完成， 其速率由 Shockley–Read–Hall 公式给出：

U = R − G = pn − ni2 τp(n + n1) + τn(p + p1) 2.1

其中 n1、p1 是与缺陷能级位置有关的特征浓度。 这个式子的结构值得注意：分子就是偏离平衡的程度（pn − ni2）。 平衡时分子为零，净复合为零——这正是细致平衡的要求。

在低注入（少数载流子增量远小于多子浓度）条件下，式 2.1 退化为一个极其简洁的形式： 净复合率正比于少子的过剩量，

U ≈ Δnτ   （低注入，τ 为少子寿命） 2.2

2.3 寿命与扩散长度：少子的"人生半径"

少子在被复合掉之前，平均能存活 τ 的时间；在这段时间里它一边做热运动、 一边受浓度梯度驱动而扩散，平均能走出 L 的距离。两者通过扩散系数联系起来：

L = √​( D τ ) 2.3

这个长度是 PN 结物理中最重要的空间尺度之一：它决定了"结"能影响到多远。 本页取 Dn = 35 cm²/s、Dp = 12.5 cm²/s、 τ = 1 μs，得到 Ln ≈ 59 μm、Lp ≈ 35 μm。 相比之下耗尽区宽度只有 0.43 μm——扩散长度比耗尽区宽两个数量级， 这意味着正偏时注入的少子会深入中性区很远才被复合掉，电流由这段"少子扩散区"决定，而不是由耗尽区本身决定。

2.4 连续性方程：把产生、复合、输运串起来

任何一点的载流子浓度变化，等于"流进来的减流出去的"加上"产生的减复合的"。对电子写出这一收支：

∂n∂t = 1q ∂Jn∂x + Gn − Rn 2.4

稳态下左边为零。这条方程与泊松方程一起，构成求解任何半导体器件的完整方程组—— 但在 PN 结这个问题上，我们不需要解完整的偏微分方程组，只需要抓住它的平衡态与准平衡态。

03

费米能级：热平衡下的化学势水位

费米能级是整门课最容易被误读的概念。它不是"某个电子的能量"，而是一个统计参数—— 描述的是整个电子系统在给定温度下的化学势。理解了这一点， 后面所有关于"能带弯曲"与"费米能级拉平"的图，都会变得不言自明。

3.1 从费米分布到载流子浓度

电子在能级 E 上的占据概率由费米–狄拉克分布给出：

f(E) = 1 1 + exp​[ (E − EF) / kT ] 3.1

当 E = EF 时 f = 1/2。 所以 EF 的位置，就是"电子占据概率恰好一半"的能量位置。 当 E 比 EF 高出几个 kT 时， 指数项主导分母，分布退化为玻尔兹曼尾巴：

f(E) ≈ exp​[ −(E − EF) / kT ] 3.2

对导带底以上所有态求和（积分），便得到导带电子浓度；对价带顶以下求"空态"数，得到空穴浓度：

n = Nc exp​( −Ec − EFkT )，    p = Nv exp​( −EF − EvkT ) 3.3
概念澄清

费米能级不是电子的能量，而是电子系统的化学势。 它的严格含义是：在恒温恒容下，向系统加入一个电子所引起的自由能增量。 把 EF 画在能带图上，只是借用能量坐标来标示这个化学势的高低—— 它可以在禁带里，也可以在导带里（简并时），甚至完全不对应任何真实存在的能级。

当系统存在静电势 ψ 时，真正守恒的量是电化学势 EF = μ − qψ。 下文所说的"费米能级"，一律指这个包含静电势的电化学势。

3.2 掺杂如何移动费米能级

由式 3.3 可以直接读出规律：n 越大，Ec − EF 就必须越小。 掺入施主把电子浓度抬高，费米能级便向导带靠拢；掺入受主则相反。

3.3 热平衡的判据：费米能级处处水平

这一节是理解 PN 结的关键。载流子的输运由电化学势的梯度驱动，写成电流密度形式就是：

Jn = μn n dEFndx，     Jp = μp p dEFpdx 3.4

热平衡意味着没有净电流。没有净电流，就意味着费米能级在任何方向上都不能有梯度—— 于是它在整块材料中必须是一条水平线。这是一条充要的判据，也是检验任何能带图画得对不对的第一标准。

此处的常见困惑

"既然平衡时没有电流，为什么 PN 结的能带是弯的？"

因为能带弯曲描述的是静电势，费米能级水平描述的是没有净电流，两者是完全不同层面的信息。 内建电场确实存在，它使 Ec、Ev 随位置变化； 但与此同时，载流子浓度也按照完全相同的形状重新分布，使得"浓度梯度产生的扩散"与"电场产生的漂移"在每个位置精确抵消。 净效果为零，EF 因此保持水平。

由此立刻得到两个重要推论，它们会在第 5、6 章被反复使用：

  1. 能带的总弯曲量就等于内建电势乘以电子电荷，即 qVbi。因为 EF 水平，两端的 Ec 之差只能全部来自静电势差。
  2. 能带弯曲的形状由泊松方程决定，而不是由费米能级决定。费米能级只负责"画一条水平线"，剩下的几何形状全部来自空间电荷分布。

3.4 温度：费米能级的"回归本征"倾向

温度升高时，本征载流子浓度按 exp(−Eg/2kT) 急剧上升， 逐渐追上甚至超过掺杂浓度。费米能级随之向禁带中央 Ei 靠拢—— 掺杂的效果被热激发"淹没"。当 ni 接近 ND 时，材料失去 n 型特征， 器件失效。硅器件的最高工作温度（约 150–200 °C）正是由这条规律设定的。

04

结的形成：扩散、空间电荷与内建电场的三方平衡

把一块 n 型半导体和一块 p 型半导体接成一体，接触瞬间会发生一连串连锁反应。 这个反应链只有四个环节，但它自我终止、自我稳定——最终的产物就是 PN 结。

4.1 连锁反应的四步

  1. 浓度梯度引发扩散。n 区电子浓度 1016、p 区只有 104， 相差 12 个数量级；空穴则相反。巨大的浓度梯度驱动电子向 p 区扩散、空穴向 n 区扩散。 这一步与电场无关，纯粹是热运动的统计学结果。
  2. 电离杂质被留下，形成空间电荷。电子走了，但它所属的施主原子（已电离为正离子） 被固定在晶格上动弹不得。于是 n 区界面附近积累了正电荷；同理，p 区界面附近积累了 负的受主离子。这些电荷不能移动，称为空间电荷。
  3. 空间电荷建立电场。正负电荷层之间产生由 n 指向 p 的电场。 同时，界面附近的载流子已被扩散走、又得不到补充，浓度降到极低——这片区域被称为 耗尽区（或空间电荷区）。
  4. 电场产生反向漂移，直到平衡。电场把电子往 n 区推、把空穴往 p 区推， 方向恰好与扩散相反。扩散越强，积累的电荷越多，电场越强，漂移也越强。 当两者在每个位置都精确抵消时，系统达到热平衡，净电流为零，反应停止。

4.2 扩散电流的定量形式

扩散电流正比于浓度梯度，比例系数是扩散系数 D。注意空穴的电流方向与浓度梯度方向相反 （因为空穴带正电，且沿"浓度降低"的方向流动）：

Jn,diff = qDn dndx，     Jp,diff = −qDp dpdx 4.1

4.3 漂移电流与爱因斯坦关系

漂移电流由电场驱动，比例系数是迁移率 μ：

Jn,drift = qμnnE，     Jp,drift = qμppE 4.2

现在把平衡条件代入：令 Jn = Jn,diff + Jn,drift = 0， 并用 E = −dψ/dx。把式 3.3 的 n(x) 求导可得 dn/dx = (n/kT)·q(dψ/dx)， 代回后电场项与浓度项同时消去，只剩一个与材料、掺杂、位置全部无关的关系：

Dnμn = Dpμp = kTq = VT ≈ 25.85 mV （300 K） 4.3 · 爱因斯坦关系

这个关系的物理含义值得多说一句：扩散与漂移不是两种独立的机制，而是同一个热运动在不同观察角度下的表现。 载流子的随机热运动既造成净扩散（当存在梯度时），也造成漂移（当存在电场时），两者被同一个温度参数绑在一起。 这也是为什么在热平衡下，它们必然能够精确抵消——它们本来就同源。

4.4 一个必须澄清的误解

常见错误

"PN 结的内建电场可以驱动电流，所以能对外输出功率。"

这是错的，而且在概念上错得很彻底。在热平衡下，内建电场产生的漂移电流与扩散电流大小相等、方向相反， 净电流恒为零。用一个外电路把两端连起来，什么也不会发生——因为两端之间没有电化学势差 （EF 处处相同）。

内建电场能做的唯一一件事，是阻止载流子在浓度梯度下继续流失。它是一个"守门人"，不是一个"发动机"。 要让 PN 结输出功率，必须外加能量（光照），而那正是太阳能电池的原理——注意，此时费米能级会发生分裂， 系统不再处于热平衡。

05

定量描述：泊松方程、内建电势与耗尽宽度

定性图像已经完整，接下来把它写成方程。这一章的所有结果，都只依赖两个输入： 空间电荷的分布形状，以及"费米能级必须水平"这个边界条件。

5.1 泊松方程与耗尽近似

电势与电荷分布由泊松方程联系。在耗尽区内，自由载流子已被"清空"， 电荷几乎全部来自电离杂质离子：

d2ψdx2 = −ρ(x)εs，    ρ = { −qNA (−xp < x < 0)；+qND (0 < x < xn)；0 (其余) } 5.1

这就是耗尽近似：把耗尽区内的载流子浓度当作零。它的合理性来自数量级—— 耗尽区内的载流子浓度比电离杂质浓度低好几个数量级，对电荷的贡献可以忽略。这个近似在 正偏较大时会失效（那时注入的载流子与背景电荷可比），这也是"大注入效应"的来源。

5.2 内建电势：两种等价推导

路径一（能带法，最直观）。EF 水平，所以两端的 Ec 之差就是全部的电势能差。把式 3.3 写两次（分别对 n 区与 p 区），相减即得：

qVbi = kT ln​ NANDni2   ⟹   Vbi ≈ 0.71 V （NA=ND=1016） 5.2

路径二（电流法，更严格）。直接令 Jn = 0 并对整个结积分， 会得到完全相同的结果。两条路径的等价性，正是"费米能级水平"与"净电流为零"这两个陈述互为充要条件的体现。

式 5.2 有一个值得注意的性质：内建电势由两侧的掺杂浓度之比决定，而且只按对数增长。 掺杂提高一个数量级，Vbi 只增加约 60 mV。硅器件的 Vbi 因此被牢牢锁定在 0.6–0.9 V 区间， 无法通过掺杂显著改变。

5.3 耗尽宽度与电场分布

对式 5.1 积分两次，并施加"电场在耗尽区边界处为零"的边界条件，得到耗尽宽度：

W = √​( 2εs(Vbi − V)q ( 1NA + 1ND ) ) 5.3

其中 V 是外加偏压（正偏为正）。两个关键结论：

  • 正偏使 W 变窄（Vbi − V 减小），反偏使 W 变宽。这就是变容二极管的工作原理。
  • 耗尽区向轻掺杂一侧延伸得更多：xpNA = xnND。掺杂低的一侧需要更宽的空间来"摊开"同样多的电荷。这就是为什么 p+n 结的耗尽区几乎全部落在 n 区。

6.3 三个容易被忽略的细节

  1. 耗尽区并非"完全没有载流子"。它只是载流子浓度远低于电离杂质浓度。 在结中心，n 与 p 都降到 ni 量级（1010）， 而不是零。这也解释了为什么反偏时耗尽区里仍有"产生电流"——那里的载流子虽少，却仍在被不断产生。
  2. 过渡是连续的，不是阶跃的。图 6 中的曲线在耗尽区内是一条平滑的斜线（对数坐标下近似线性）， 因为电势在那里按抛物线变化，而浓度按电势的指数变化。
  3. 乘积恒定，各自剧变。在整条曲线上任取一点，np 都精确等于 ni2。 这是热平衡的标志，也是判断"这张图是不是平衡态"的快捷方法。
07

少子与多子：非平衡下的分工

加上偏压之后，系统离开热平衡。此时"费米能级"这个概念需要被拆成两个， 而正是这个拆分，把 PN 结从一个静态结构变成了一个有源器件。

7.1 低注入：多子负责维持电中性

正向偏置时，p 区的空穴被推向 n 区，n 区的电子被推向 p 区。但在正常工作范围内， 注入的少子数量远小于该区的多子浓度——这就是低注入条件。它的后果是：

  • 多子浓度的相对变化极小（千分之一量级），因此中性区依然保持电中性；
  • 为了维持电中性，多子会自动重新分布去"中和"注入的少子，这个过程几乎不消耗电压；
  • 中性区内几乎没有电场（电中性 ⇒ 泊松方程给出 ∇·E ≈ 0），因此少子在中性区只靠扩散运动。

一句话概括这种分工：多子是背景，少子是信号。电压几乎全部降落在耗尽区上， 电流却主要由中性区里的少子扩散决定。

7.2 边界条件：整流的微观起源

正偏压 V 使势垒从 qVbi 降到 q(Vbi − V)， 越过势垒进入对方的载流子数量按玻尔兹曼因子增加。结果是耗尽区边界处的少子浓度被指数放大：

np(xp) = np0 exp​( qVkT )，     pn(xn) = pn0 exp​( qVkT ) 7.1

这个指数因子 eqV/kT 就是整流的全部秘密：电压每增加 60 mV，结边少子浓度就增加十倍，电流也随之增加十倍。 反偏时 V < 0，指数因子趋近于零，少子被"抽走"而不是注入—— 这就是反偏电流极小且几乎不随电压变化的原因。

7.3 准费米能级：把"一个"拆成"两个"

非平衡状态下，电子与空穴各自与晶格达到平衡（各自内部有明确的温度与化学势）， 但彼此之间不再平衡。因此需要为它们各自定义一个费米能级：

n = Nc exp​( −Ec − EFnkT )，    p = Nv exp​( −EFp − EvkT ) 7.2

两者相乘，得到一个把"偏离平衡的程度"直接写成能级差的表达式：

np = ni2 exp​( EFn − EFpkT ) 7.3

在理想 PN 结中，准费米能级之差恰好等于外加电压所对应的能量： EFn − EFp = qV。 于是式 7.3 直接告诉你系统处于哪种状态：

  • 正偏（V > 0）：EFn 高于 EFp，np > ni2，结内净复合占优——注入的载流子在这里互相湮灭，复合电流由此产生。
  • 反偏（V < 0）：EFn 低于 EFp，np < ni2，结内净产生占优——耗尽区不断产生电子-空穴对，被电场扫出，形成产生电流。
  • 平衡（V = 0）：两条准费米能级重合为一条，回到第 3 章的水平线。

08

从微观到宏观：肖克利方程

现在把所有碎片装配起来。中性区里少子只做扩散，扩散过程中不断被复合， 这构成一个简单的一维边值问题——它的解，就是那条著名的指数曲线。

8.1 少子扩散方程

在 n 区（x > xn），空穴是少子， 没有电场，只有扩散与复合。稳态连续性方程化为：

Dp d2Δpndx2 − Δpnτp = 0   ⟹   Δpn(x) = Δpn(xn) exp​( −x − xnLp ) 8.1

解的形式很直观：注入的少子在离开结边后按指数衰减，特征长度正是扩散长度 Lp。在 x = xn 处对它求导， 就得到结边处的扩散电流；把 p 区一侧的电子电流同样算出并相加：

J = Js ( exp​( qVkT ) − 1 )，    Js = qni2 ( DpLpND + DnLnNA ) 8.2 · Shockley 方程

8.2 逐项解读

  • 指数项来自式 7.1 的边界条件——它是整流的直接来源。正偏时它迅速增大； 反偏超过几个 kT/q 后，它就趋于零，电流被"−1"钉死在 −Js。
  • Js 与电压无关，只由材料参数与温度决定。 它正比于 ni2，而 ni2 ∝ exp(−Eg/kT)—— 这解释了反向饱和电流随温度指数上升，以及禁带越宽、反向漏电越小 （SiC、GaN 能耐受高压的微观原因之一）。
  • 分母里的掺杂浓度说明：掺杂越重，Js 越小。 这与直觉一致——重掺杂意味着少子基数小，能被"抽"出来的载流子也就少。
  • 温度每升高 10 °C，反向电流约翻一倍。这不是故障，而是式 8.2 的必然结果， 也是二极管温度传感器的物理基础。

09

二维视角：NPN 结构中的载流子输运

前面八章都停留在一维剖面上：只看一个坐标 x，只看一个结。 现在把剖面展开成二维，并在同一块硅片上背靠背放两个结。 这不是引入新物理——而是把第 7 章的"少子扩散 + 准费米能级分裂"同时用在两个方向上， 让注入、扩散、复合、扫出这四个动作在同一幅图里同时发生。

9.1 为什么偏偏是 NPN

把一块 p 型硅的两侧各做一块 n 型区，就得到 N⁺–P–N 三明治结构。两个结的分工是刻意不对称的：

  • 左边的 EB 结（发射结）正偏。势垒被压低，左边的 N⁺ 区（发射区）向中间很薄的 P 区（基区）大量注入电子。发射区重掺杂（1018），保证注入的是电子而不是空穴。
  • 右边的 BC 结（集电结）反偏。耗尽区变宽、电场变强，落在基区里的少数载流子一旦扩散到它的边缘，就被电场扫进右边的 N 区（集电区）。
  • 基区必须极薄。本模型取 1.6 μm，扣除两侧耗尽区后中性基区只有约 0.94 μm，而电子扩散长度 Ln 是 59 μm。比值 0.016 意味着电子穿过基区的时间远短于它的寿命——绝大多数电子来不及复合就被集电结收走。这就是"晶体管"三个字的全部技术含义。
与第 7 章的直接对应

第 7.2 节的边界条件 np(xp) = np0eqV/kT 在这里变成了发射结的注入源；第 7.3 节的准费米能级分裂 EFn−EFp = qV 在这里分别发生在两个结上：EB 结分裂 +qVBE，BC 结分裂 −qVCB。 同一个式子，用了两次，方向相反。

9.4 模型的边界：哪些是物理，哪些是示意

任何可视化都必须交代它的适用范围。本模型在以下意义上是物理的： 耗尽宽度、内建电势、结边少子浓度、扩散长度、输运系数全部由解析式实时计算； 载流子的漂移方向由电场（能带梯度）决定，中性区无场、只做扩散； 复合只发生在电子与空穴空间上真正相遇的位置。

以下几项是为可视化而做的简化，不应被当作定量结果：

  • 只画平均速度，不画热运动。真实载流子每秒发生数十次随机碰撞，单条轨迹是折线； 本模型只保留这些碰撞在统计上的净结果——漂移速度与扩散净流速， 因此每个粒子沿一条确定的流线前进。这是为可读性做的取舍，也是本模型与真实单粒子轨迹的唯一重大差异。
  • 耗尽宽度由解析式给定，不迭代求解自洽泊松方程，因此不体现大注入下的场分布畸变。
  • 粒子是"宏观粒子"，数目按浓度的对数压缩；图中各区的真实浓度以文字标注为准。
  • 基区复合概率被显著上调，以便在有限时间内观察到复合事件；真实器件的 αT > 0.999，复合远比图上稀疏。
  • 忽略速度饱和、雪崩击穿与二维边缘效应（y 方向视为均匀，等价于无限宽的平板）。

9.6 放大从何而来：一个阀门，不是一台泵

先破除一个几乎人人都有的误解：晶体管不产生能量。它做的全部事情， 是用一个小信号去控制一股很大的能量流——能量来自电源 VCC，晶体管只决定"开多大"。 所以严格说，BJT 不是放大器，而是一个受控阀门；"放大"是阀门加上电源之后的整体效果。

为什么小信号能控制大能量？因为基极与集电极之间隔着一个反偏的结： 它像一道阻抗极高的闸门，本身几乎不耗电，但通过的电流完全由基极说了算。 放大由此分成两条彼此独立的链条。

链条一：电流放大 —— 一个空穴换来一百个电子

发射区重掺杂（1018）、基区极薄（中性区不到 1 μm，比扩散长度 59 μm 小两个数量级）， 这两件事合起来保证：注入基区的电子绝大多数来不及复合，就扩散到了集电结边缘。 基极电流只需补充那极小的一部分复合损失。于是电流的分配变成下面这样：

链条二：电压放大 —— 指数响应

如果只有电流分配，BJT 还只是个电流放大器：想要 1 A 的集电极电流，就得喂 10 mA 的基极电流。 真正让"放大"变得惊人的，是第二条链条：IC 与 IB 都由同一个变量控制， 而且是指数关系。

两条链条合起来，才构成"放大"

单看电流增益 β，BJT 只是个电流中继器；单看指数曲线，它只是只二极管。 两者叠加之后才出现真正的放大：输入端是正偏结，动态电阻只有 VT/IB，很小； 输出端是反偏结，可以接上很大的负载电阻而不影响收集效率。 同一个 ΔIC，在输出端能撑起大得多的 ΔV。电压增益 Av = gmRL 因此可以做到几十甚至上千倍—— 而付出的代价，只是基极那一点点电流。

放大的边界

输出电流不能超过 VCC/RL 所允许的上限（饱和）， 输入电压不能低于开启电压（截止），集电结反偏过高会击穿。 放大只发生在这三条边界围出的区域内——这正是"放大区"这个名字的来历。 回到模型里切换三个模式，你看到的正是这三个区域。

四个非理想效应：教科书没画的那部分

前面九章把 BJT 画得太干净了：基区宽度固定、电流均匀铺满发射极、耗尽区只随偏压变化。 真实的器件不是这样。下面四个效应，全部源于同一件事—— 基区的几何边界不是常数，它会被电流和电压推动。 它们也是"为什么必须用二维模型"的最好理由。

10.1 发射极电流集边效应

基极电流不是从正上方垂直流进基区的。它必须从两侧的基极接触出发，横向穿过基区， 才能到达发射结下方。基区很薄，薄层电阻却有几百 Ω/□，这段横向路径是一个实实在在的电阻。

横向电流在基区里产生压降，于是发射结各处的实际正偏压沿横向递减： 靠近基极接触的边缘正偏最强，发射极中心最弱。而电流密度对 VBE 是指数的， 横向差 26 mV，电流就差 e 倍。结果是大电流下电流几乎全部从发射极边缘流过。

10.2 基区扩展效应（Kirk 效应）

集电结的耗尽区里，空间电荷本应只由电离的施主离子提供。但穿行其间的电子也是电荷—— 只是平时数量太少，可以忽略。当集电极电流密度上升到

JK = q vsatNC  ≈  1.6×104 A/cm² （NC = 1016 cm−3，vsat ≈ 107 cm/s） 10.1

时，电子的负电荷已经抵消掉集电区的正电荷。净空间电荷反号，电场分布崩溃，集电结的 有效位置被推向集电极——基区的边界跟着往外挪，这就是"基区扩展"。

10.3 基区宽度调制效应（厄利效应）

这一条最容易理解，后果却最深远：增大 VCB，集电结耗尽区变宽，而它向基区一侧的扩展 会吃掉一部分中性基区。基区变窄，少子浓度梯度变陡，集电极电流随之上升——即使 VBE 一动不动。

IC ≈ qDnnp0WB(VCB) exp​( VBEVT ) 10.2

10.4 基区穿通

把 10.3 推到极端：如果基区本来就极薄、集电区掺杂又低，那么 VCB 升高时集电结耗尽区会一路向基区内推进。 当它与发射结的耗尽区相接时，中性基区彻底消失，两个势垒连成一片—— 发射极与集电极之间只剩一个由耗尽区电场决定的势垒，基极再也无法控制电流。这就是穿通。

穿通不是雪崩击穿（那是靠碰撞电离），而是纯粹的几何失效： 基区这块"缓冲垫"被耗尽了。所以它的发生电压与 VCB 有关、与基区厚度的平方成正比， 却几乎与温度无关——这一点常被用来在实验中区分穿通与雪崩。

10.5 四个效应其实是一件事

把四个效应并排看，会发现它们的共同点非常明确：基区的有效边界不是版图上画出来的那条线， 而是由外加电压和通过它的电流共同决定的。

与第 9 章模型的对应

第 9 章的粒子模型里，基区宽度是被写死的常数——那正是"教科书器件"。 本章四个效应全部来自"基区宽度会动"这一件事。把它们画进二维剖面就能看清： 一维分析给出工作点，二维分析才给出边界。

而那四个效应现在也能在模型里直接看到：切到集边 / Kirk / 厄利 / 穿通四个模式， 同一个粒子引擎会改变注入的横向分布或基区边界，让 α、集电区收集速率跟着变。 第 10 章的静态图讲"是什么"，模型里的四个模式演示"怎么发生"。

四个常见误解的澄清

这一章不是补充新知识，而是拆掉几个几乎人人都会踩的坑。它们之所以顽固， 是因为每一个都"看起来很像对的"。

误解一

"耗尽区里没有载流子。"

耗尽区只是"载流子浓度远低于电离杂质浓度"，不是真空。在结中心，电子与空穴浓度都降到 ni 量级（约 1010 cm−3），比两侧少子还高。 这个残留浓度正是反偏产生电流的来源——若真的是零，就无从"产生"了。

误解二

"正偏压把势垒完全抵消了，所以电流畅通。"

正偏只是把势垒从 qVbi 降到 q(Vbi−V)， 在开启电压附近仍有约 0.1 eV 的势垒存在。真正让电流上升的，不是势垒消失了， 而是能越过残余势垒的载流子数量按指数增加。即使势垒只降低 60 mV，越过去的载流子就多一倍。

误解三

"费米能级就是电子占据的那个能级。"

费米能级是一个统计量，不是任何电子的实际能量。它可以在禁带中间，也可以进入导带或价带（简并半导体）。 它的唯一确定含义是：f(EF) = 1/2，以及"加入一个电子所需的自由能"。 把 EF 理解为"水位"是恰当的——水位是一个整体属性，不是水分子的属性。

误解四

"载流子浓度高的地方一定向浓度低的地方流，所以 PN 结会一直有电流。"

扩散不是唯一的输运机制。浓度梯度建立起来的同时，也建立起了电场；电场产生的漂移恰好反向。 最终的稳态由电化学势的梯度决定，而不是由浓度梯度单独决定。 在热平衡下，电化学势处处相等，所以净电流为零——哪怕浓度相差十二个数量级。

12

要点总结

如果只记住十句话，应该是这十句。

  1. 质量作用定律是全部讨论的支点。np = ni2 锁定的是乘积，不是各自的浓度。掺杂改变的是一种载流子，另一种则被反比锁定。
  2. 产生与复合是一对可逆过程。热平衡时二者严格抵消（细致平衡）；偏离平衡时，净复合率正比于 np − ni2，这个差值就是"离平衡有多远"的度量。
  3. 硅中的复合主要经由缺陷能级（SRH）完成。辐射复合在间接带隙材料中概率极低——这正是硅不能做高效发光器件的根本原因。
  4. 费米能级是化学势，不是电子的能量。它决定占据概率，其位置随掺杂移动，随温度上升向禁带中央回归。
  5. 热平衡的判据是费米能级处处水平。因为电流正比于电化学势的梯度。这是检验任何能带图的第一标准。
  6. 能带弯曲与费米能级水平并不矛盾。前者描述静电势，后者描述无净电流。二者共存，恰恰是"有电场、无电流"的图形化表达。
  7. PN 结的形成是扩散自我终止的过程。扩散留下固定离子 → 产生电场 → 电场产生反向漂移 → 漂移增强到与扩散抵消 → 系统稳定。没有任何外部干预。
  8. 内建电场不是电源。它只阻止载流子流失，不对外做功。热平衡下它的漂移电流与扩散电流精确抵消，净电流为零。
  9. 多子维持电中性，少子决定电流。正偏时注入的少子在中性区按 L = √(Dτ) 的特征长度扩散衰减，这段"少子扩散区"才是电流的真正来源。
  10. 非平衡时费米能级分裂为两条准费米能级。EFn − EFp = qV；正偏时 np > ni2 净复合，反偏时 np < ni2 净产生。整条肖克利方程都长在这个分裂上。

一句话总结

PN 结是一个自我稳定的浓度梯度结构：扩散制造了电场，电场又阻止了扩散， 两者在每一个位置上精确抵消。费米能级水平，是这个平衡的签名； 而一旦有外加电压把这个签名撕开一道 qV 的口子， 载流子就会以指数级的不对称性涌过——这就是整流的全部。
